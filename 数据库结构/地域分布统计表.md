## 地域分布统计表

dashboard_region_stats

| 字段          | 数据类型        | 约束                      | 说明                        |
| ----------- | ----------- | ----------------------- | ------------------------- |
| id          | bigint      | 主键、自增、非空                | 自增主键                      |
| stat_date   | date        | 非空、联合唯一                 | 统计日期                      |
| stat_type   | varchar(20) | 非空、联合唯一                 | 统计粒度：daily/weekly/monthly |
| region      | varchar(50) | 非空、联合唯一                 | 省份/地区                     |
| news_count  | int         | 可空，默认0                  | 发文量                       |
| create_time | datetime    | 非空，默认 CURRENT_TIMESTAMP | 创建时间                      |
