## 办件用户上传信息表

| 字段          | 数据类型         | 约束                 | 说明                                                                                 |
| ----------- | ------------ | ------------------ | ---------------------------------------------------------------------------------- |
| text_id     | bigint       | NOT NULL<br><br>主键 | 唯一id                                                                               |
| case_id     | bigint       | NOT NULL           | 对应的办件id，是case表的case_id的外键                                                          |
| user_id     | bigint       | NOT NULL           | 是user表的user_id的外键                                                                  |
| type        | int          | NOT NULL           | 表示该信息对应的办件流程<br><br>0：办理意见<br><br>1：归档意见<br><br>2：启用说明<br><br>3：停用说明<br><br>4：异常说明 |
| content     | VARCHAR(300) |                    | 用户上传的具体文本                                                                          |
| create_time | DATETIME     |                    | 创建时间，默认当前时间                                                                        |
