## dashboard_stats 表

**表说明**：大屏统计快照表

| 字段                   | 数据类型         | 约束                                                  | 说明                        |
| -------------------- | ------------ | --------------------------------------------------- | ------------------------- |
| id                   | bigint       | 主键、自增、非空                                            | 自增主键                      |
| stat_date            | date         | 非空、联合唯一                                             | 统计日期                      |
| stat_type            | varchar(20)  | 非空、联合唯一                                             | 统计粒度：daily/weekly/monthly |
| total_news           | bigint       | 可空，默认0                                              | 信息总量                      |
| total_news_article   | bigint       | 可空，默认0                                              | 信息总量-文章                   |
| total_news_video     | bigint       | 可空，默认0                                              | 信息总量-视频                   |
| total_alert          | bigint       | 可空，默认0                                              | 预警信息总量                    |
| total_alert_article  | bigint       | 可空，默认0                                              | 预警信息总量-文章                 |
| total_alert_video    | bigint       | 可空，默认0                                              | 预警信息总量-视频                 |
| total_case           | bigint       | 可空，默认0                                              | 办件总量                      |
| case_in_progress     | int          | 可空，默认0                                              | 办理中                       |
| case_finished        | int          | 可空，默认0                                              | 已办结                       |
| case_conversion_rate | decimal(5,2) | 可空，默认0.00                                           | 转化率%                      |
| today_news           | bigint       | 可空，默认0                                              | 今日信息量                     |
| today_news_article   | bigint       | 可空，默认0                                              | 今日信息量-文章                  |
| today_news_video     | bigint       | 可空，默认0                                              | 今日信息量-视频                  |
| today_news_yoy       | decimal(6,2) | 可空，默认0.00                                           | 今日信息量同比%                  |
| today_alert          | bigint       | 可空，默认0                                              | 今日预警信息量                   |
| today_alert_yoy      | decimal(6,2) | 可空，默认0.00                                           | 今日预警同比%                   |
| today_alert_level1   | int          | 可空，默认0                                              | 今日预警一级                    |
| today_alert_level2   | int          | 可空，默认0                                              | 今日预警二级                    |
| today_alert_level3   | int          | 可空，默认0                                              | 今日预警三级                    |
| create_time          | datetime     | 非空，默认 CURRENT_TIMESTAMP                             | 创建时间                      |
| update_time          | datetime     | 非空，默认 CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间                      |
