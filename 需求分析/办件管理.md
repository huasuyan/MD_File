#### 4.2.5 办件管理

| 功能名称     | 功能说明                                       | 前置条件                                                 | 业务流程                                           |                                                                                         | 异常处理 |
| -------- | ------------------------------------------ | ---------------------------------------------------- | ---------------------------------------------- | --------------------------------------------------------------------------------------- | ---- |
| 用户动作     | 系统响应                                       |                                                      |                                                |                                                                                         |      |
| 预警记录转为办件 | 用户在查看预警记录时，可以点击“转为办件”按钮，填写必要信息，将该条预警记录转为办件 | 1. 用户已登录<br>    <br>2. 处于预警记录页面<br>    <br>3. 存在预警记录 | 1. 点击“转为办件”按钮<br>    <br>2. 填写办件相关信息，点击“确认”按钮  | 2. 前端用表单参数调用后端接口，后端在办件处理表中新建一项，返回前端创建成功信息。 前端页面显示“转为办件成功”                               |      |
| 办理办件     | 用户填写“办理意见”信息，将办件状态修改为“办理中”                 | 1. 用户已登录<br>    <br>2. 处于办件管理页面的“待办”分区               | 1. 点击“办理意见”按钮。填写具体内容并提交<br>    <br>2. 点击“办理”按钮 | 1. 后端保存用户提交的办理意见<br>    <br>2. 查询该办件是否已存在办理意见，如果存在，则将办件状态改为“办理中”。如果没有，则先让用户填写办理意见，再修改状态 |      |
| 归档办件     | 用户填写“归档意见”信息，将办件状态修改为“已归档”                 | 1. 用户已登录<br>    <br>2. 处于办件管理页面的“办理中”分区              | 1. 点击“归档意见”按钮。填写具体内容并提交<br>    <br>2. 点击“归档”按钮 | 1. 后端保存用户提交的归档意见<br>    <br>2. 查询该办件是否已存在归档意见，如果存在，则将办件状态改为“已归档”。如果没有，则先让用户填写归档意见，再修改状态 |      |
| 启用办件     | 用户填写“启用说明”信息，将办件状态修改为关闭前状态                 | 1. 用户已登录<br>    <br>2. 处于办件管理页面的“已关闭”分区              | 1. 点击“启用办件”按钮，填写启用说明并提交                        | 1. 同时新增办件上传信息表和修改办件管理表状态                                                                |      |
| 关闭办件     | 用户填写“停用说明”信息，将办件状态修改为“已关闭”                 | 1. 用户已登录<br>    <br>2. 处于办件管理页面的非“已关闭”分区             | 1. 点击“关闭案件”按钮，填写停用说明并提交                        | 1. 同时新增办件上传信息表和修改办件管理表状态                                                                |      |
| 标记异常办件   | 用户填写“异常说明”信息，将办件状态修改为“异常”                  | 1. 用户已登录<br>    <br>2. 处于办件管理页面的“待办”/“办理中”分区         | 1. 点击“归档”按钮，填写异常说明并提交                          | 1. 同时新增办件上传信息表和修改办件管理表状态                                                                |      |
| 条件查询办件   | 用户可以输入特定参数，查询对应办件，或者获取当前可见所有办件             | 1. 用户已登录<br>    <br>2. 具有办件管理权限                      | 1. 点击“办件办理”按钮<br>    <br>2. 输入特定参数，点击“查询”按钮    | 1. 默认显示待办的所有办件信息<br>    <br>2. 显示符合特定参数、当前分区下的办件信息                                      |      |
